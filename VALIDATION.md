# Проверка сборки · 11 октября 2026

Проверено на Windows, Python 3.14.8 с Tkinter. Код использует возможности стандартной библиотеки Python 3.10+; отдельные запуски на Linux/macOS и Python 3.10 не выполнялись.

## Автоматические проверки

```text
python -m unittest discover -s tests -v
Ran 53 tests
OK
```

Все 53 теста выполнены, GUI-тест не пропущен. Полный вывод включён в ZIP-сборку как `test-results.txt`; генерируемый журнал не хранится в Git-репозитории.

Проверено:

- точное покрытие количества целыми стаками; сравнение с полным перебором комбинаций на 80 случайных наборах;
- отсутствие повторного использования объявления, нехватка объёма, налог и округление;
- переходы между уровнями, текущий EXP, HQ, остановка последней повторной сдачи, expansion caps;
- large-scale allowances, бюджет закупки заранее, дорога, отсутствие цен;
- выход рецепта, количества ингредиентов/кристаллов, альтернативные и недоступные рецепты;
- одиночные/пакетные ответы Universalis, раздельные HQ/NQ запросы, пакет до 50 ID;
- повреждённый кэш/JSON, неверная схема, TTL, устаревший ответ и предел его возраста, 429/404;
- целостность реального каталога, сумма нескольких слотов сдачи, промежуточные уровни 52/54;
- **160 сочетаний профессия/рубеж**: восемь профессий × уровни 1, 5, 10, …, 95, с реальным каталогом и искусственными тестовыми ценами;
- создание Tkinter-окна, расчёт в отдельном потоке, заполнение таблицы, выбор строки и подробности покупки. Окно во время теста скрыто.
- новая версия: числовая сортировка в обоих направлениях, неизвестные суммы в конце, приоритеты стоимости/прибыли/принятий/allowances, совместная работа фильтров, сброс, финансовые знаки и CSV видимых строк в текущем порядке.
- исправление подсказки HQ: воспроизведены фильтры «Крафт + HQ» с выключенной галочкой, включение галочки без пересчёта, затем пересчёт Carpenter Lv 45 / EXP 132. После пересчёта HQ-крафт появляется; DEMO использован только для рыночных цен.

## Проверка внешних источников

Успешно получены последняя версия английских игровых таблиц и все семь CSV из закреплённого commit. Снимок прошёл проверку полноты: 1 120 leves, 1 012 рецептов, 1 657 предметов, EXP для уровней до 100.

Universalis успешно ответил на запросы миров, DC и пакетные рыночные запросы. Выполнен полный расчёт Carpenter Lv 20 → 25 для DC Light, бюджет 100 000 gil, 100 allowances, налог 5%, дорога 0. API-предупреждений не было. Цены при итоговой повторной проверке брались из только что заполненного кэша.

В этом рыночном снимке первый вариант: **Driving Up the Wall, купить HQ**, 11 принятий / 11 сдач / 11 allowances; расход −2 362 gil, базовая суммарная награда +7 700 gil, баланс **+5 338 gil**. Это результат проверки, а не фиксированная рекомендация для будущих цен.

Параметры, дата и первые 10 рассчитанных вариантов включены в ZIP-сборку как `example-live-result.json`. Этот временный рыночный снимок не хранится в Git-репозитории. Дата записана с UTC+05:00; DEMO-цены в этот файл не включены.
